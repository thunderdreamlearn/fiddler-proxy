## ❓ What Is Fiddler

| **Term** | **Description** |
|-----------|-----------------|
| **Proxy** | Intercepts HTTP(S) traffic |
| **TLS Decrypt** | Reads encrypted sessions |
| **AutoResponder** | Rewrite responses |
| **FiddlerScript** | Custom C# logic |
| **Composer** | Replay + craft requests |
| **Throttle** | Simulate slow networks |

**Why use Fiddler?**
- ✅ Debug APIs fast
- ✅ Inspect mobile traffic
- ✅ Test error handling
- ✅ Rewrite responses live
- ✅ Free
